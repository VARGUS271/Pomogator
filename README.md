# Помогатор (Workout Planner)
Скрипт спрашивает, какой инвентарь есть (гантели, скакалка, турник и т.д.)
и сколько времени есть на тренировку, затем генерирует план: сколько блоков
и какой длительности отвести на каждый снаряд, не выходя за лимит времени.
Пример входа: `гантели, скакалка`, `1 час` → план: 2 блока гантели + 1 блок скакалка с отдыхом.

## Технологический стек
- Python 3.10+ (только стандартная библиотека: random, re)
- Git + GitHub (ветки main/develop, pull requests)
- Mermaid для диаграмм в документации

## Запуск
python pomogator.py
